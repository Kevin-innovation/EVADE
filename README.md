# EVADE

EVADE는 브라우저에서 즐기는 웨이브 생존 액션 로그라이크 게임입니다. 몬스터의 물결 속에서 살아남으며 경험치로 레벨업하고, 3가지 업그레이드 중 하나를 선택해 점점 강해지세요. 전투에서 모은 골드는 메인 메뉴의 연구 강화에서 영구 업그레이드로 사용합니다.

## 실행 방법
- 로컬에서 `index.html`을 브라우저로 열면 바로 실행됩니다.
- 추가 설치나 빌드가 필요하지 않습니다.

## 조작법 (키보드 전용)
- 이동: 방향키(← ↑ → ↓)
- 기본 공격(슬래시): Space
- 스킬: Q / W / E / R
- 일시정지: ESC
- 음소거/해제: M (설정 화면에서 볼륨 조절 가능)
- 디버그 오버레이: F3

메뉴/선택 조작
- 모든 메뉴(메인, 캐릭터 선택, 연구 강화, 설정, 일시정지, 게임오버)는 방향키로 이동하고 Enter로 선택/확정합니다.
- 레벨업 카드도 방향키로 이동, Enter로 선택/확정합니다.

## 핵심 게임플레이
- 생존: 시간이 지날수록 강해지는 적 웨이브를 버티며 가능한 오래 생존하세요.
- 전투: Space로 근접 슬래시, QWER 스킬로 전황을 유리하게 만드세요.
- 경험치/레벨업: 적이 드랍하는 보석을 모아 레벨업 → 3가지 강화 중 하나 선택.
- 골드/메타 진화: 적 처치로 골드를 습득, 게임 종료 후 메인 메뉴의 연구 강화에서 영구 업그레이드 구매.

## 시스템 요약
- 적 타입: 근접, 원거리(궁수), 엘리트(주기 출현), 보스(주기 출현)
  - 원거리 적(궁수)의 출현 확률과 동시 수는 완만하게 증가하도록 튜닝되었습니다.
- 보스: 체력바 HUD 표시, 링/콘 탄막을 교대 발사하며 체력 비율에 따라 패턴 강화
- HUD: HP/XP/레벨/시간/처치/골드/Wave, 스킬 쿨타임 게이지(Q/W/E/R), 보스 체력바
- 이펙트: 히트스파크/스크린 셰이크/피격 오버레이, 간단 SFX(WebAudio)

## 밸런스/품질 관련 메모
- 슬래시 반경 업그레이드 상한 적용(기본 70 → 최대 160)으로 화면 전체 범위화를 방지했습니다.
- 원거리 적(궁수) 스폰 비율/동시수 상한을 조정해 난이도 급증을 완화했습니다.
- 게임오버 시 쉐이크/투사체/이펙트/엔티티를 정리하여 재시작 시 잔여 투사체로 인한 즉시 피해를 방지합니다.
